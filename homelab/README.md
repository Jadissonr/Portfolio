# 🧰 Homelab

Esta seção reúne o ambiente de laboratório pessoal usado para estudo prático de Linux, redes, virtualização e hardening de infraestrutura.

## Objetivo

O homelab serve como base para testar conceitos de:

- administração de sistemas Linux
- redes e troubleshooting
- segurança defensiva e hardening
- virtualização e provisionamento de serviços
- laboratório para aprendizado contínuo em tecnologia
