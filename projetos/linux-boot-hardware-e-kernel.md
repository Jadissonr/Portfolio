# Linux — Boot, Hardware e Kernel

Projeto de estudo focado no processo de boot, identificação de hardware e comportamento do kernel Linux.

## Objetivo

Compreender a inicialização do sistema operacional, a interação com o hardware e como o kernel organiza os componentes essenciais do ambiente Linux.

## Serviços e ferramentas

| Serviço / Ferramenta | Função |
|---|---|
| dmesg | Exibe mensagens de inicialização do kernel |
| lsblk | Lista dispositivos de bloco do sistema |
| lspci | Mostra dispositivos PCI conectados |
| lscpu | Exibe informações da CPU e arquitetura |
| systemd targets | Define modos operacionais do sistema |

## Aprendizados principais

- estrutura do processo de boot em Linux
- identificação de dispositivos e arquitetura do hardware
- leitura de mensagens do kernel em diagnósticos de sistema
- entendimento de componentes essenciais para manutenção e troubleshooting
