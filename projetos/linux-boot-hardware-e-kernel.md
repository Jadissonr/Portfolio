# Linux - Boot, Hardware e Kernel

Projeto de estudo focado no processo de boot, identificação de hardware e comportamento do kernel Linux.

## Serviços e Ferramentas

| Serviço | Função |
|---|---|
| dmesg | Exibe mensagens de inicialização do kernel |
| lsblk | Lista dispositivos de bloco do sistema |
| lspci | Mostra dispositivos PCI conectados |
| lscpu | Exibe informações da CPU e arquitetura |
| systemd targets | Define modos operacionais do sistema |
