# Linux Fundamentals — Terminal e Processos

Estudo prático sobre uso do terminal Linux, gerenciamento de processos, serviços e observabilidade do sistema.

## Objetivo

Reforçar conceitos fundamentais de administração Linux por meio do uso do terminal, análise de processos e monitoramento de serviços.

## Serviços e ferramentas

| Serviço / Ferramenta | Função |
|---|---|
| Bash | Interface de linha para executar comandos e automatizar tarefas |
| ps | Exibe processos em execução no sistema |
| kill | Encerra processos específicos |
| systemctl | Gerencia serviços e unidades do sistema |
| journalctl | Consulta logs do sistema e serviços |

## Aprendizados principais

- uso de comandos essenciais para monitoramento e diagnóstico
- gerenciamento de processos e serviços em ambientes Linux
- leitura de logs e identificação de falhas operacionais
- automação via shell e execução de tarefas em linha de comando
